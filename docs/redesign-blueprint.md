## 动效清单

| 层级 | 对象 | 目的 | 时长 / 位移 | reduced-motion |
|---|---|---|---|---|
| Signature | 票根撕开、飞行、落位 | 解释从封面进入档案 | 1200–1800ms；保留空间关系 | Enter 或拖动后短淡入并直接完成 |
| Section | About、Timeline、Work 首次进入 | 建立章节节奏 | 420–700ms；Y 12–20px | 仅短淡入 |
| Section | 时间轴进度线与当前年份 | 显示经历推进 | 由真实滚动位置驱动 | 保留静态 active 状态 |
| Component | 项目窗口打开 / 关闭 | 说明文件夹到窗口的关系 | 220–320ms；小范围 clip/opacity | 立即切换 |
| Component | 项目文本 tab / 节点详情 | 反馈内容切换 | 220–280ms；Y ≤ 12px | 立即切换 |
| Feedback | 文本链接、文件夹、节点、红点 | 说明可操作性 | 120–180ms；文件夹 Y 3–5px | 保留颜色、线条和文字状态 |
| Ambient | AG-UI 事件流点、播放电平 | 表示流式通信或播放状态 | 低速、低对比循环 | 停止循环，结构与进度仍可读 |
| Cursor | 点 + 外环跟随 | 在细指针设备补充 OPEN/DRAG/PLAY/VISIT | rAF + transform | 停用并恢复系统指针 |

## 实现裁决

- 保留 `useTicketTransition.js` 的状态机和 `transition-complete` 事件，不引入路由或动效库。
- 页面改为文档级原生连续滚动；导航点击才使用平滑滚动。
- 使用 `portfolio.js` 作为日期、能力和四项目文案的单一数据源。
- 四项目入口同规格，不默认打开任何项目；跨工艺项目只存在于时间轴。
- 缺陷视频和 Ganttodo iframe 只在对应项目打开后挂载。
- 未确认的阿里云职责、指标和内部结构只进入交接清单，不出现在访客可见页面。
- 音乐没有现成合法素材；先寻找可核验的公共领域 / CC0 本地音源并记录来源，找不到则在交接中标记，不做空壳。
